`search/absolute.csv` — 네이버 통합 검색량 절댓값 (keyword × date wide 형식)

`sometrends/sometrend_mention_long.csv` — SomeTrend 플랫폼 언급량 (long 형식, 블로그·인스타그램 컬럼). 487개 키워드 커버

`keyword_select/keywords_selected_500_seed1527267025.csv` — appearance 사분위 계층 샘플링으로 선정한 500개 키워드 목록

## 피처 (348개)

`build_dataset.py`가 60일 lookback 윈도우에서 생성

신호별 73개 × 4신호(search, click, blog, instagram) = 292개:
- 기존 통계 (43개/신호): volume(4), level(4), growth(4), accel(3), rsi(2), skew(2), kurt(2), spikiness(4), cv(4), lag(5), std(3), pos(5), days_since_max(1)
- 동적 피처 (23개/신호): slope(3d/7d/14d), norm_slope, slope_change, trend_r2, residual_energy, curvature, vol_ratio, range_squeeze, damping, zero_crossings, direction_streak, reversal, band_position, band_width, drawdown, breakout_strength, band_approach, daily_return, daily_returns_avg, momentum_divergence, daily_accel
- 일별 변화율 (7개/신호): change_1d_ago ~ change_7d_ago

교차 피처 25개: ratio/lead/pos_gap (8) + 교차상관 시차/방향 동조/기울기 괴리 (12) + 시차 크기 괴리 lead_magnitude (3) + weighted_slope_strength + activation_spread

서지 피처 10개: blog/instagram 각 surge_intensity(3d/7d), surge_accel(3d/7d), surge_lead_days

멀티채널 종합 20개: past_conversion_rate(×5), past_channel_active(×5), multi_accel(×4), past_buzz_zscore(×5), conv_trend(1)

캘린더 1개: month

## 라벨 (15개 = 5종 × 3윈도우)

FW=15, 4채널 합산 기준, 모든 윈도우(5d/10d/15d)에서 산출

- `intensity_Nd` — 미래 N일 4채널 합산 평균 (버즈 크기)
- `buzz_composite_Nd` — lookback 대비 4채널 z-score 가중합, clip [-10,10] (상대적 버즈)
- `growth_Nd` — 과거 N일 대비 미래 N일 4채널 가중 성장비 (ratio, 1=변화없음, 학습 시 log 변환)
- `sustainability_Nd` — 현재 대비 미래 평균 유지율, 분모 floor 적용, clip [0,5]
- `crash_Nd` — 현재에서 최저점까지 하락률 (0=안빠짐, 양수=빠짐)

## 학습 파이프라인

`train.py` CLI 옵션:
- `--data` — 데이터셋 경로 (기본: data/processed/dataset.csv)
- `--target` — 학습 타겟 (단일 라벨명 또는 `all`)
- `--tune` — Optuna TPE 하이퍼파라미터 튜닝 활성화
- `--n_trials` — Optuna trial 수 (기본 25)
- `--gpu` — CUDA GPU 학습
- `--train-stride` — train/valid 서브샘플링 간격 (기본 3, test는 항상 stride=1)

시계열 분할: train → 75일 gap → valid → 75일 gap → test (GAP = LB 60 + FW 15)
