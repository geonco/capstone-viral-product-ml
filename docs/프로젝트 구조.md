# 프로젝트 구조

식품(과자/베이커리) 키워드의 바이럴 강도를 예측하는 ML 파이프라인

## 전체 구조

```

│   ├── features/                    #   피처·라벨 생성
│   │   └── build_dataset.py  # 271피처 + 9라벨 데이터셋 빌드
│   └── training/                    #   학습·평가
│       ├── train.py                 #   LightGBM 학습 (Optuna TPE 튜닝, SHAP)
│       ├── config.py                #   271 FEAT_COLS + LABEL_COLS 정의
│       └── data_loader.py           #   CSV 로드 + 컬럼 검증
│
├── data/                            # 모든 데이터 (.gitignore)
│   ├── raw/                         #   수집 원본 (불변)
│   │   ├── search/                  #     네이버 검색 트렌드 (absolute, trend)
│   │   ├── shopping_click/          #     쇼핑 클릭 (absolute, trend, 성별/연령별)
│   │   ├── sometrends/              #     SomeTrend 언급량 (블로그, 인스타그램)
│   │   ├── keyword_pool/            #     키워드 후보군 원본
│   │   └── keyword_select/          #     선정된 500개 키워드 목록
│   └── processed/                   #   빌드된 학습 데이터셋
│       └── dataset_YYYYMMDD_HHMMSS.csv
│
├── outputs/                         # 실험 결과 (.gitignore)
│   └── run_YYYYMMDD_HHMMSS_{target}/
│       ├── figures/                  #   SHAP plot, 차트
│       ├── metrics/                  #   evaluation_results.csv, shap_importance.csv, best_params.json
│       └── models/                   #   LightGBM 모델 weight
│
├── docs/                            # 설계 문서
├── CLAUDE.md                        # 프로젝트 지침
└── .gitignore
```

## 데이터 흐름

```
data/raw/ (4개 소스)
    ↓
build_dataset.py --stride 1
    ↓
data/processed/dataset_YYYYMMDD_HHMMSS.csv (271피처 + 9라벨)
    ↓
train.py --target buzz_rank --tune --train-stride 3
    ↓
outputs/run_YYYYMMDD_HHMMSS_buzz_rank/ (모델, SHAP, 평가지표)
```

## 원본 데이터 (data/raw/)

4개 소스, 약 500개 식품 키워드 × 2022-01 ~ 2026-02 일별 데이터

`search/absolute.csv` — 네이버 통합 검색량 절댓값 (keyword × date wide 형식)

`shopping_click/absolute.csv` — 네이버 쇼핑 클릭 수 절댓값. 같은 폴더에 성별(gender_m/f_pct.csv), 연령대별(age_10~60_pct.csv) 클릭 비율도 포함

`sometrends/sometrend_mention_long.csv` — SomeTrend 플랫폼 언급량 (long 형식, 블로그·인스타그램 컬럼). 487개 키워드 커버

`keyword_select/keywords_selected_500_seed1527267025.csv` — appearance 사분위 계층 샘플링으로 선정한 500개 키워드 목록

## 피처 (271개)

`build_dataset.py`가 60일 lookback 윈도우에서 생성

신호별 61개 × 4신호(search, click, blog, instagram) = 244개:
- 기존 유지 (39개/신호): volume, level, growth, accel, rsi, skew, kurt, spikiness, cv, lag, std, pos, days_since_max
- 신규 동적 피처 (22개/신호): slope(3d/7d/14d), norm_slope, slope_change, trend_r2, residual_energy, curvature, vol_ratio, range_squeeze, damping, zero_crossings, direction_streak, reversal, band_position, band_width, drawdown, breakout_strength, daily_return, daily_returns_avg, momentum_divergence, daily_accel

교차 피처 20개: ratio, lead, pos_gap (기존 8) + 교차상관 시차, 방향 동조, 기울기 괴리 (신규 12)

서지 피처 6개: blog/instagram 각 surge_intensity, surge_accel, surge_lead_days

캘린더 1개: month

## 라벨 (9개)

v1 (기존 4개): future_intensity, future_acceleration, signal_agreement, search_click_convergence

v2 (신규 5개): buzz_composite, momentum_score, channel_breadth, conversion_shift, buzz_rank

## 학습 파이프라인

`train.py` CLI 옵션:
- `--data` — 데이터셋 경로 (미지정 시 data/processed/ 최신 파일 자동 선택)
- `--target` — 학습 타겟 (단일 라벨명 또는 `all`)
- `--tune` — Optuna TPE 하이퍼파라미터 튜닝 활성화
- `--n_trials` — Optuna trial 수 (기본 25)
- `--gpu` — CUDA GPU 학습
- `--train-stride` — train/valid 서브샘플링 간격 (기본 3, test는 항상 stride=1)

시계열 분할: train → 74일 gap → valid → 74일 gap → test (GAP = LB 60 + FW 14)
