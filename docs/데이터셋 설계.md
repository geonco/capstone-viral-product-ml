# 데이터셋 설계

## 개요

`build_dataset.py`가 생성하는 데이터셋의 피처와 라벨 정의. 과자/베이커리 키워드 약 500개에 대해 60일 lookback으로 피처를 산출하고, 14일 forward로 라벨을 산출

4개 시그널 각각에서 65개 피처를 생성하여 260개, 교차 시그널 20개, 서지 10개, 멀티채널 종합 19개, 캘린더 1개를 더해 총 310개 피처. 라벨은 8개

시그널 정의:
- `search` — 네이버 통합 검색량 절댓값 (소비자 관심도)
- `click` — 네이버 쇼핑 클릭 수 절댓값 (구매 의향)
- `blog` — SomeTrend 블로그 언급량. 해당 키워드가 포함된 **게시글 수**를 카운트하며, 댓글·좋아요·조회수는 미포함. "이 키워드에 대해 글을 쓴 사람 수"에 해당하는 콘텐츠 생산 지표이며, 관심도(소비)와는 다름
- `instagram` — SomeTrend 인스타그램 언급량. 공개 게시물만 크롤링하며, 블로그와 동일하게 게시글 수 기반. API 제한으로 커버리지 제한적

SomeTrend 데이터에는 1~3일의 수집 지연이 존재하며, 콘텐츠 소비(조회)가 아닌 콘텐츠 생산(작성)을 측정하므로 검색보다 2~14일 후행하는 패턴이 관찰됨. 이는 "콘텐츠 소비 → 검색 → 구매 → 리뷰 작성"의 순서를 반영. 상세 분석은 `docs/시그널 선후관계 분석.md` 참고

라벨의 채널 가중치(search 0.4, click 0.3, blog 0.2, insta 0.1)는 이 분석에 기반하여 신호 안정성·선행성 순서로 설정

## 변수와 약어

`t`는 예측 시점 인덱스. 이 시점 이전 60일로 피처를, 이후 14일로 라벨을 계산

약어는 `{시그널}_{구간}` 형식:
- 시그널 — `s`(search, 네이버 검색), `c`(click, 네이버 쇼핑 클릭), `b`(blog, 블로그 언급), `i`(instagram, 인스타그램 언급)
- 구간 — `lb`(lookback, t-60~t의 과거 60일 배열), `fw`(forward, t~t+14의 미래 14일 배열)

예시: `s_lb`는 "검색 시그널의 과거 60일 데이터", `c_fw`는 "클릭 시그널의 미래 14일 데이터"

`baseline`은 `mean(lb)`, 즉 60일 전체 평균. `EPS`는 0 나눗셈 방지 상수(1e-6)

멘션 데이터가 없는 키워드는 영벡터(zeros)로 대체. NaN은 ffill 후 0으로 채움 (bfill 미사용 — 미래 데이터로 과거를 채우는 시간적 누수 방지)

## 윈도우 규칙

피처에 따라 사용하는 윈도우 세트가 다름:
- `W_SHORT = [3, 7, 14, 30]` — volume, level, growth, spikiness. 바이럴은 3일 만에 터질 수 있으므로 3d 포함
- `W_FULL = [3, 5, 7, 14, 30]` — growth 내부 계산(accel에 필요), position
- `W_STAT = [7, 14, 30]` — cv, std. 통계량은 최소 7개 데이터포인트 필요
- `[14, 30]` — rsi, skew, kurt. RSI는 7d가 노이즈, skew/kurt는 7개로도 불안정
- `W_MULTI = [1, 3, 7, 14, 30]` — 멀티채널 종합. 바이럴 초기 1~3일 감지를 위해 단기 포함

## 시그널 피처 (시그널당 65개 × 4 = 260개)

### A. Scale — 이 키워드가 실제로 얼마나 큰가 (4개)

정규화하지 않은 절대 볼륨. 검색량 2만인 키워드와 30인 키워드에서 같은 50% 성장이 가지는 의미가 다르다는 것을 모델이 구분할 수 있는 유일한 수단

`{sig}_volume_{n}d` = `mean(lb[-n:])`. n = 3, 7, 14, 30

### B. Level — 자기 역사 대비 지금 어디에 있는가 (4개)

60일 전체 평균 대비 최근 n일의 상대적 위치. 1.0이면 평소 수준, 2.0이면 평소의 2배

`{sig}_level_{n}d` = `mean(lb[-n:]) / (baseline + EPS)`. n = 3, 7, 14, 30. clip [0, 30]

### C. Momentum — 올라가는 중인가, 내려가는 중인가 (4개)

직전 n일과 그 이전 n일을 비교한 성장률. 양수면 상승, 음수면 하락

`{sig}_growth_{n}d` = `mean(lb[-n:]) / (mean(lb[-2n:-n]) + EPS) - 1`. n = 3, 7, 14, 30. clip [-2, 20]

### D. Acceleration — 성장 속도 자체가 빨라지고 있는가 (3개)

서로 다른 윈도우의 growth 차이. 양수면 가속(점점 더 빠르게 성장), 음수면 감속

- `{sig}_accel_short` = `growth_3d - growth_7d` — 초단기 가속. 급등 초입에서 큰 양수
- `{sig}_accel_mid` = `growth_7d - growth_14d` — 중단기 가속
- `{sig}_accel_long` = `growth_14d - growth_30d` — 장기 모멘텀 방향

### E. RSI — 얼마나 꾸준히 올랐는가 (2개)

금융의 Relative Strength Index를 적용한 모멘텀 지표. growth가 "얼마나 올랐나"라면, RSI는 "얼마나 꾸준히 올랐나"를 측정. 매일 조금씩 올랐으면 RSI 높고(70~80), 하루에 몰빵이면 낮음(40~50). 지속적 상승 vs 일시적 스파이크를 구분

`{sig}_rsi_{n}d`. n = 14, 30. 범위 [0, 100]. 7d는 데이터포인트 부족으로 제외

### F. Shape — 최근 패턴이 바이럴처럼 생겼는가

바이럴 스파이크가 만들어내는 특유의 비대칭·뾰족한 분포를 직접 포착하는 피처

**Skewness — 비대칭도 (2개)**

`{sig}_skew_{n}d`. 정규화된 값의 3제곱 평균. 오른쪽 꼬리가 길면 양수. 하루만 크게 튀어도 skewness가 급등. n = 14, 30

**Kurtosis — 뾰족함 (2개)**

`{sig}_kurt_{n}d`. 정규화된 값의 4제곱 평균 - 3. 극단값이 있으면 양수. "이 윈도우에 스파이크가 있었는가"를 직접 측정. n = 14, 30

**Spikiness — 최대값 돌출도 (4개)**

`{sig}_spikiness_{n}d` = `max(lb[-n:]) / (mean(lb[-n:]) + EPS)`. 최대값이 평균 대비 얼마나 튀는지. skew/kurt보다 단순하지만 3일처럼 짧은 윈도우에서도 작동. n = 3, 7, 14, 30

### G. Stability — 얼마나 안정적이고, 안정성이 변하고 있는가

안정적이던 키워드가 갑자기 흔들리기 시작하면 바이럴 전조일 수 있음

**CV — 변동계수 (3개)**

`{sig}_cv_{n}d` = `std(lb[-n:]) / (mean(lb[-n:]) + EPS)`. 0이면 안정, 클수록 들쑥날쑥. n = 7, 14, 30. clip [0, 10]

**CV Change — 안정성 변화 (1개)**

`{sig}_cv_change` = `cv(lb[-14:]) - cv(lb[:30])`. 최근 14일 변동성과 초기 30일 변동성의 차이. 양수면 최근이 더 불안정해진 것

### H. Lag — 특정 시점에 실제로 얼마였는가 (5개)

윈도우 기반 요약이 아닌 특정 날의 실제값. Kaggle M5 대회 우승 솔루션에서 가장 강력한 피처로 입증

`{sig}_lag_{n}d` = `lb[-n] / (baseline + EPS)`. n = 1, 3, 7, 14, 30. lag_1d는 "어제 값", lag_7d는 "지난주 이맘때"

### I. Raw Std — 실제 변동 크기 (3개)

CV는 스케일 중립적 변동성이지만, 절대 변동 크기도 별도로 필요. 트리 모델은 곱셈을 직접 수행하지 못하므로 cv × volume에서 std를 유도할 수 없음

`{sig}_std_{n}d` = `std(lb[-n:])`. n = 7, 14, 30

### J. Position — 최근값이 n일 최고점 대비 어디 있는가 (5개)

level이 60일 평균 대비 위치라면, position은 최근 n일 최고점 대비 위치. 1.0이면 현재가 n일 내 최고, 0이면 고점 대비 크게 하락

`{sig}_pos_{n}d` = `mean(lb[-3:]) / (max(lb[-n:]) + EPS)`. 분자를 3일 이동평균으로 smoothing. n = 3, 5, 7, 14, 30

### K. Peak Recency — 최고점이 며칠 전에 나타났는가 (1개)

`days_since_{sig}_max_14d` = `13 - argmax(lb[-14:])`. 0이면 어제가 최고점, 13이면 14일 전이 최고점

### L. Micro-Trend — 기울기, 곡률, 추세 품질 (8개)

단순 성장률로는 잡히지 않는 추세의 "모양"을 포착. 선형 기울기뿐 아니라 비선형 곡률, 추세의 설명력(R²)까지 포함

- `{sig}_slope_3d/7d/14d` — 최근 3/7/14일 선형 회귀 기울기
- `{sig}_norm_slope_7d` — 기울기를 baseline으로 정규화
- `{sig}_slope_change` — `slope_3d - slope_7d`. 기울기가 가팔라지는 중인지
- `{sig}_trend_r2_7d` — 7일 추세의 R². 1이면 완벽한 직선, 0이면 추세 없음
- `{sig}_residual_energy_7d` — `1 - R²`. 추세로 설명되지 않는 노이즈 비율
- `{sig}_curvature_14d` — 14일 2차 다항식의 2차 계수. 양수면 가속 곡선, 음수면 감속 곡선

### M. Wave Dynamics — 진동, 감쇠, 방향 전환 (6개)

시계열의 파동적 특성. 진동이 커지는지 줄어드는지, 방향 전환이 잦은지

- `{sig}_vol_ratio` — 7일 변동성 / 30일 변동성. 1보다 크면 최근이 더 요동
- `{sig}_range_squeeze` — 7일 범위 / 30일 범위. 줄어들면 에너지 축적(돌파 전조)
- `{sig}_damping` — 최근 7일 진폭 / 이전 7일 진폭. 1 이하면 감쇠, 이상이면 증폭
- `{sig}_zero_crossings_14d` — 14일간 방향 전환 횟수. 많으면 불규칙, 적으면 일관된 추세
- `{sig}_direction_streak` — 같은 방향 연속일 수 (부호 포함). +5면 5일 연속 상승
- `{sig}_reversal_3d` — 최근 3일 내 방향 전환 발생 여부 (0/1)

### N. Regime/Breakout — 볼린저 밴드, 돌파 강도 (4개)

현재값이 과거 변동 범위를 벗어났는지 판단. 볼린저 밴드(30일 평균 ± 2σ) 기준

- `{sig}_band_position` — 밴드 내 위치. 0이면 하단, 1이면 상단, 1 초과면 돌파
- `{sig}_band_width` — 밴드 폭 / 평균. 좁으면 안정기, 넓으면 변동기
- `{sig}_drawdown_14d` — 현재값의 14일 고점 대비 하락률
- `{sig}_breakout_strength` — `(현재값 - 상단밴드) / σ`. 양수면 돌파 강도

### O. Daily Momentum — 일별 변화율, 다이버전스 (4개)

가장 짧은 시간 단위의 모멘텀. 어제 대비 오늘의 변화

- `{sig}_daily_return_1d` — 어제 대비 오늘 변화율
- `{sig}_daily_returns_3d_avg` — 최근 3일 일별 변화율의 평균
- `{sig}_momentum_divergence` — RSI 방향과 slope 방향이 불일치하면 1. 추세 전환 전조
- `{sig}_daily_accel_1d` — 일별 변화율의 변화율 (2차 미분)

## 교차 시그널 피처 (20개)

검색만 올라가는 건 일시적 관심이지만, 클릭·블로그·인스타가 같이 움직이면 실제 확산

### 기존 교차 (8개)

- `click_search_ratio` — 검색 대비 클릭 활성도 비율. clip [0, 50]
- `click_lead_7d/14d` — 클릭 성장률 - 검색 성장률. 양수면 클릭이 검색을 선행
- `click_search_pos_gap` — 클릭과 검색의 상대 위치 차이
- `blog_lead_7d`, `blog_search_ratio` — 블로그 기준 동일 계산
- `instagram_lead_7d`, `instagram_search_ratio` — 인스타그램 기준 동일 계산

### 교차상관·동조 (12개)

- `{prefix}_search_best_lag` — 해당 시그널이 검색을 몇 일 선행하는지 (0~7)
- `{prefix}_search_peak_xcorr` — 최적 시차에서의 상관 강도
- `{prefix}_search_dir_agree` — 최근 7일 방향 일치율 (0~1)
- `blog_search_slope_gap`, `insta_search_slope_gap` — 기울기 괴리
- `multi_slope_count` — 양의 기울기를 보이는 시그널 수 (0~4)

prefix: blog, insta, click

## 서지 피처 (10개)

블로그·인스타그램에서 검색보다 먼저 나타나는 선행 급등 신호. 3d와 7d 윈도우로 초기 서지도 포착

- `{platform}_surge_intensity_3d/7d` — 최근 3/7일 최대값 / baseline - 1. 얼마나 폭발적인지
- `{platform}_surge_accel_3d/7d` — 최근 3/7일 기울기 / baseline. 얼마나 빠르게 올라가는지
- `{platform}_surge_lead_days` — 플랫폼 피크와 검색 피크 간 시차 (양수 = 플랫폼 선행)

platform: blog, instagram

## 멀티채널 종합 피처 (19개)

단일 시그널이 아닌 4채널을 교차 합산한 종합 지표. 단기 윈도우(1d, 3d)를 포함하여 바이럴 초기 1~3일 감지 가능

### past_conversion_rate — 과거 구매 전환율 (5개)

`click / (search + blog + insta)`. n일 평균 기준. 높으면 검색 대비 구매 의향이 높은 키워드

n = 1, 3, 7, 14, 30. 1d는 "어제 전환율", 3d는 "최근 3일 전환율" — 갑작스런 전환율 급등 감지

### past_channel_active — 활성 채널 수 (5개)

최근 n일 평균이 과거 중앙값을 초과하는 채널 수 (0~4). 여러 채널이 동시에 뜨면 바이럴 신호

n = 1, 3, 7, 14, 30

### multi_accel — 4채널 가중 가속도 (4개)

4채널 각각에서 최근 n일 vs 이전 n일을 비교하고 가중 합산(search 0.4, click 0.3, blog 0.2, insta 0.1). clip [-1, 1]

n = 3, 7, 14, 30. 1d는 이전 기간 비교 불가로 제외

### past_buzz_zscore — 최근이 과거 대비 얼마나 튀는가 (5개)

4채널 각각에서 최근 n일 평균의 z-score를 구해 가중 합산. 양수면 과거 대비 최근이 비정상적으로 활발

n = 1, 3, 7, 14, 30

## 캘린더 피처 (1개)

`month` — 1~12. 식품 키워드의 계절 패턴(3월 화이트데이, 12월 크리스마스 등) 포착. day_of_week는 SHAP=0으로 제거

## 라벨 (8개)

### 순수 미래 라벨

미래 14일 데이터만으로 산출. 피처와 같은 과거 데이터를 공유하지 않으므로 target leakage 없음

**1. future_intensity — 앞으로 2주간 얼마나 뜰까**

4채널 미래 14일 평균 볼륨 합산. 높을수록 많이 뜨는 키워드. 학습 시 log1p 변환 적용

마케터 활용: 값이 높으면 캠페인 투자 가치 큼 [MacKinlay, 1997]

**2. future_acceleration — 트렌드가 더 타오르는 중인가, 꺾이는 중인가**

미래 14일을 전반/후반 7일로 나눠 비교. 양수면 성장 중, 음수면 감속 중. [-1, 10]

마케터 활용: 양수 → 지금 투입하면 효과 있음, 음수 → 추격 비효율 [Skok, 2012]

**3. signal_agreement — 진짜 트렌드인가, 한 채널만 뜨는 건가**

4채널 미래 움직임의 pairwise 상관계수 평균. [-1, 1]. 1이면 전 채널 동조

마케터 활용: 높으면 크로스채널 캠페인, 낮으면 특정 채널 집중 [Abhishek et al., 2012]

**4. search_click_convergence — 검색하는 사람이 실제로 구매도 하는가**

검색↔클릭의 min-max 정규화 후 상관계수. [-1, 1]. 양수면 구매 의향 높은 트렌드

마케터 활용: 높으면 퍼포먼스 마케팅, 낮으면 인지도 캠페인 [Li & Kannan, 2014]

### 과거+미래 혼합 라벨

"과거 대비 미래가 얼마나 변했는가"가 예측 대상이므로 과거 데이터를 의도적으로 포함. target leakage 가능성 있음

**5. buzz_composite — 과거 대비 얼마나 더 뜨거워졌는가**

채널별 z-score 가중 합산 (search 0.4, click 0.3, blog 0.2, insta 0.1). 양수면 과거보다 활발

**6. momentum_score — 4채널 종합 가속도**

future_acceleration의 멀티채널 확장판. 4채널 가중 week1 vs week2 비교. [-1, 1]

## 품질 필터

- lookback 앞 30일이 전부 비활성(NaN 또는 0)이면 해당 샘플 제외
- lookback 전체의 search 표준편차가 0이면 제외
- signal_agreement 계산 시 std=0인 상수 시그널은 사전 필터링
