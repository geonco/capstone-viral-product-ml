# 라벨 설계 — 순수 미래 데이터 기반 바이럴 예측 타겟

## 재설계 배경

기존 라벨(virality_score, concordance 등)은 과거 60일 lookback 통계(mean, std, p75, max)를 산정식에 포함. 동일한 과거 60일에서 산출한 피처와 타겟 간 정보 누출(target leakage) 발생 → 모델이 미래 예측이 아닌 과거 분모 역산을 학습할 위험

재설계 원칙:
- 모든 라벨을 미래 14일 forward window 데이터만으로 산출
- 과거 lookback 데이터(mean, std, percentile 등) 산정식 참조 일절 금지
- 마케팅 의사결정에 직접 활용 가능한 지표 구성

## 변수 정의

`s_fw`는 예측 시점 t부터 t+14까지의 검색(search) 일별 볼륨 배열(길이 14). `c_fw`는 동일 구간 쇼핑 클릭(click) 볼륨. `b_fw`는 블로그 언급 수, `i_fw`는 인스타그램 언급 수. 네 시그널 모두 동일한 14일 forward window에서 추출하며, 멘션 데이터가 없는 키워드는 영벡터(zeros)로 대체

`EPS`는 영나눗셈 방지용 상수(1e-6). `FW`는 forward window 길이(14)

## 라벨 정의

### 1. future_intensity — 4채널 합산 버즈 볼륨

`future_intensity = mean(s_fw) + mean(c_fw) + mean(b_fw) + mean(i_fw)`

값의 범위는 [0, +inf). 검색·클릭·블로그·인스타그램 4개 채널의 평균 볼륨을 합산한 총 버즈 규모. 학습 시 log1p 변환 적용

마케터 활용: "이 키워드가 향후 2주간 얼마나 주목받을 것인가"를 단일 수치로 파악. 높을수록 캠페인 투자 가치가 큰 키워드

학술 근거: 이벤트 스터디(event study) 방법론의 누적 이상 거래량(Cumulative Abnormal Volume, CAV) 개념을 마케팅에 적용. 금융 경제학에서 이벤트 윈도우 내 총 비정상 활동을 측정하는 데 사용하며, 이를 검색·소셜 시그널로 확장 [MacKinlay, 1997, "Event Studies in Economics and Finance"]

### 2. future_acceleration — 주간 성장률

`w1 = mean(s_fw[0:7])`, `w2 = mean(s_fw[7:14])`
`future_acceleration = (w2 - w1) / (w1 + EPS)`

값의 범위는 [-1, 10] (clip 적용). 양수면 2주차가 1주차보다 커서 트렌드가 가속 중이고, 음수면 감속 중

마케터 활용: 양수 → "아직 성장 중이므로 마케팅 투입 적기", 음수 → "이미 꺾인 트렌드, 추격 비효율적". 값이 0 근처면 안정적 지속 관심

학술 근거: 바이럴 계수(K-factor) 개념에서 착안. 그로스 해킹 문헌에서 K > 1이면 자기 강화 성장, K < 1이면 자연 소멸로 판단하는 것과 유사한 논리 [Skok, 2012, "Lessons Learned — Viral Marketing"]

### 3. signal_agreement — 멀티채널 동조도

mean > EPS인 비영(non-zero) 시그널들 간 pairwise Pearson 상관계수의 평균. 시그널이 1개 이하면 0.0 반환

값의 범위는 [-1, 1]. 1에 가까우면 모든 채널이 동시에 같은 방향으로 움직이는 "진짜 트렌드", 0 근처면 채널 간 괴리가 있는 "플랫폼 한정 현상"

마케터 활용: 높은 동조도 → 크로스채널 캠페인 적합, 낮은 동조도 → 특정 채널 타겟 마케팅이 효율적

학술 근거: 교차상관(cross-correlation) 분석 기법. 신호처리 분야에서 두 시계열의 동시성(contemporaneous correlation)을 측정하는 표준 방법. 마케팅에서는 크로스채널 어트리뷰션(cross-channel attribution) 분석에 적용 [Abhishek et al., 2012, "Media Exposure through the Funnel"]

### 4. trajectory_class — 미래 곡선 형태

`peak_day = argmax(s_fw)`, `slope = polyfit(arange(14), s_fw, 1)[0]`
`fw_cv = std(s_fw) / (mean(s_fw) + EPS)`

분류 규칙:
- 0 (spike_decay): `peak_day <= 4 and slope < 0` — 초반 급등 후 하락
- 1 (slow_build): `slope > 0 and peak_day >= 10` — 후반부로 갈수록 상승
- 2 (plateau): `|slope| < mean(s_fw) * 0.01 and fw_cv < 0.3` — 안정적 횡보
- 3 (volatile): 나머지 — 불규칙 변동

마케터 활용:
- spike_decay → 실시간 소셜 콘텐츠에 적합하나 제품 기획에는 부적합
- slow_build → 브랜드 포지셔닝·신제품 론칭 최적 타이밍
- plateau → 기본 재고 계획에 활용 가능한 안정 수요
- volatile → 모니터링 유지, 과잉 투자 지양

학술 근거: 시계열 형태 분류(time series shape taxonomy). Hyndman의 Forecasting: Principles and Practice (FPP2/3)에서 제시하는 트렌드 패턴 유형화와 S-곡선(diffusion curve) 문헌에 기반 [Hyndman & Athanasopoulos, 2021, "Forecasting: Principles and Practice, 3rd ed."]

### 5. search_click_convergence — 검색-클릭 수렴도

`s_fw`, `c_fw` 각각을 자체 14일 윈도우 내에서 min-max 정규화한 뒤 Pearson 상관계수 산출. 어느 한쪽의 range가 EPS 이하(상수 시그널)이면 0.0 반환

값의 범위는 [-1, 1]. 양의 상관이면 검색과 쇼핑 클릭이 같은 날 동시에 오르내리는 "구매 의향이 높은 트렌드", 음의 상관이면 "관심은 있으나 구매로 이어지지 않는" 패턴

마케터 활용: 높은 수렴도 → 퍼포먼스 마케팅(구매 전환) 집중, 낮은 수렴도 → 인지도 캠페인(awareness) 중심 전략

학술 근거: 마케팅 퍼널(awareness → consideration → purchase) 모델에서 상위 퍼널(검색)과 하위 퍼널(클릭/구매) 간 전환 동역학 분석. 크로스채널 어트리뷰션 문헌에서 검색-커머스 상관을 구매 의향 프록시로 활용 [Li & Kannan, 2014, "Attributing Conversions in a Multichannel Online Marketing Environment"]
