# 새 데이터셋 피처 정의

## 개요

`build_dataset_20260403.py`가 생성하는 데이터셋의 전체 피처를 정의하는 문서. 기존 v1(51개)/v2(107개)와 완전 독립된 설계이며, "바이럴 예측에 어떤 정보가 필요한가"에서 출발하여 처음부터 구성

핵심 변경은 다음과 같음
- 기존 MA/growth/slope/std 중심의 기본 시계열 통계에서 탈피
- 분포 형태(skewness, kurtosis), 금융 모멘텀(RSI), burst detection(spikiness), 안정성 변화(cv_change), lag 피처 등 바이럴 예측 연구에서 입증된 피처를 도입
- 모든 피처를 스케일 중립 또는 명시적 절대규모로 설계하여 키워드 간 비교 가능하게 함
- SomeTrend 멘션 데이터를 블로그와 인스타그램 두 플랫폼으로 분리 (커뮤니티 58% 0, 뉴스 88% 0으로 희소성 과도하여 제외)
- virality_score를 ratio 방식에서 z-score 방식으로 변경
- NaN 처리에서 bfill 제거하여 시간적 누수 방지
- 인구통계 피처 미포함 (추후 ablation으로 판단)

총 210개 피처와 2개 라벨로 구성되며, 60일 lookback과 14일 forward 윈도우 사용

## 변수 정의와 데이터 흐름

`t`는 예측 시점 인덱스로, 이 시점 이전 60일의 데이터로 피처를 계산하고 이후 14일의 검색량으로 라벨을 산출. `arr_lb`는 `signal[t-60 : t]` 구간의 길이 60 배열이며, 인덱스 0이 가장 오래된 값(t-60), 인덱스 -1이 예측 직전(t-1)에 해당. `baseline`은 `mean(arr_lb)`로 60일 전체 평균을 의미. `ε`은 1e-6으로 0 나눗셈 방지 상수

데이터 흐름은 원시 CSV 로드 → NaN 처리(ffill → 0, bfill 미사용) → 키워드별·시점별 피처 계산 → DataFrame 구성 → CSV 저장 순서

## 시그널 정의 (4종)

본 데이터셋은 4개 시그널을 사용. `search`는 네이버 데이터랩 검색량 절대값이고, `click`은 네이버 쇼핑인사이트 클릭수 절대값. `blog`는 SomeTrend에서 수집한 블로그 플랫폼 언급량이고, `instagram`은 인스타그램 플랫폼 언급량

4개 시그널 모두 동일한 구조의 50개 피처를 생성하여 총 200개의 시그널 피처 산출. 여기에 교차 시그널 8개와 캘린더 2개를 더해 총 210개

## 시그널 피처 — A. Scale (시그널당 5개)

"이 키워드가 실제로 얼마나 큰가"를 모델에 알려주는 피처. 정규화하지 않은 절대값이며, 모델이 키워드 규모를 파악할 수 있는 유일한 수단. 검색량 2만인 키워드와 30인 키워드에서 동일한 50% 성장이 가지는 의미가 다르다는 것을 모델이 구분할 수 있게 해줌. volume은 이동평균(MA)과 동일한 계산이며, 절대 규모라는 역할을 명확히 하기 위해 volume으로 명명

`{sig}_volume_{n}d`는 lookback 배열의 마지막 n일 평균. n이 작을수록 현재에 가깝고, n이 클수록 과거를 포함. 클리핑 없음

- `{sig}_volume_3d` — 최근 3일 절대 규모. 지금 이 순간의 규모
- `{sig}_volume_5d` — 최근 5일 절대 규모
- `{sig}_volume_7d` — 최근 1주 절대 규모
- `{sig}_volume_14d` — 최근 2주 절대 규모
- `{sig}_volume_30d` — 최근 1달 절대 규모. 과거 규모 파악에 적합

## 시그널 피처 — B. Level (시그널당 5개)

"자기 역사에서 지금 어디 있는가"를 나타내는 상대적 위치 피처. 60일 전체 평균(baseline) 대비 최근 n일 평균의 비율로, 1.0이면 평소 수준, 2.0이면 평소의 2배 수준을 의미. 키워드마다 자기 기준으로 정규화되므로 스케일 문제 없음. 클리핑 범위 0~30

`{sig}_level_{n}d`는 `mean(arr_lb[-n:]) / (baseline + ε)`

- `{sig}_level_3d` — 최근 3일 상대 수준
- `{sig}_level_5d` — 최근 5일 상대 수준
- `{sig}_level_7d` — 최근 1주 상대 수준. 교차 시그널 피처의 기준값으로도 사용
- `{sig}_level_14d` — 최근 2주 상대 수준
- `{sig}_level_30d` — 최근 1달 상대 수준

## 시그널 피처 — C. Momentum (시그널당 5개)

"올라가고 있는가, 내려가고 있는가"를 측정하는 성장률 피처. 직전 n일 평균과 그 이전 n일 평균을 비교하여 변화율을 산출. 분자와 분모가 같은 키워드의 같은 스케일이므로 자기 정규화가 이루어짐. 양수면 상승, 0이면 정체, 음수면 하락. 클리핑 범위 -2~20

`{sig}_growth_{n}d`는 `mean(arr_lb[-n:]) / (mean(arr_lb[-2n:-n]) + ε) - 1`

- `{sig}_growth_3d` — 최근 3일 vs 이전 3일. 초단기 변화
- `{sig}_growth_5d` — 최근 5일 vs 이전 5일
- `{sig}_growth_7d` — 최근 1주 vs 이전 1주. 가장 범용적인 단기 성장률
- `{sig}_growth_14d` — 최근 2주 vs 이전 2주. 중기 추세
- `{sig}_growth_30d` — 최근 30일 vs 이전 30일. lookback 60일 전체를 사용하는 장기 비교

## 시그널 피처 — D. Acceleration (시그널당 3개)

"성장 속도 자체가 빨라지고 있는가"를 측정하는 가속도 피처. 서로 다른 윈도우의 growth 차이로 계산하며, 양수면 가속(점점 더 빠르게 성장), 음수면 감속(성장이 둔화). 트리 모델은 두 피처의 뺄셈을 직접 수행하지 못하므로, growth 값들로부터 유도 가능하더라도 명시적으로 제공

- `{sig}_accel_short`는 `growth_3d - growth_7d`로 초단기(3일)가 단기(7일)보다 더 빠르게 성장 중이면 양수. 급등 초입에서 매우 큰 양수값을 보일 수 있음
- `{sig}_accel_mid`는 `growth_7d - growth_14d`로 단기가 중기보다 빠르면 양수. 가장 범용적인 가속도 지표
- `{sig}_accel_long`은 `growth_14d - growth_30d`로 중기가 장기보다 빠르면 양수. 장기적 모멘텀 방향 판단

## 시그널 피처 — E. RSI (시그널당 3개)

금융에서 사용하는 Relative Strength Index를 시계열 데이터에 적용한 모멘텀 지표. growth가 "얼마나 올랐나"를 측정한다면, RSI는 "얼마나 꾸준히 올랐나"를 측정

`{sig}_rsi_{n}d`는 최근 n일 동안 상승일의 평균 상승폭(RS의 분자)과 하락일의 평균 하락폭(RS의 분모)을 구한 뒤, `100 - 100/(1 + RS)` 수식으로 0~100 범위의 값을 산출. n = 7, 14, 30

동일한 growth가 50%라도 매일 꾸준히 조금씩 올랐으면 RSI가 높고(70~80), 하루에 몰빵으로 올랐으면 RSI가 낮음(40~50). 바이럴 키워드가 지속적 상승세인지 일시적 스파이크인지를 구분하는 데 유용. 3d/5d RSI는 데이터포인트 부족으로 사실상 "며칠 올랐나"의 이진 판단에 가까워 제외

- `{sig}_rsi_7d` — 최근 1주 모멘텀 꾸준함. 짧은 윈도우라 변화에 민감
- `{sig}_rsi_14d` — 최근 2주 모멘텀 꾸준함. 금융 표준 기간
- `{sig}_rsi_30d` — 최근 1달 모멘텀 꾸준함. 장기 방향성 판단

## 시그널 피처 — F. Shape (시그널당 11개)

"최근 패턴이 바이럴처럼 생겼는가"를 측정하는 분포 형태 피처. 기존 v1/v2에 완전히 없었던 카테고리로, 바이럴 스파이크가 만들어내는 특유의 비대칭·뾰족한 분포를 직접 포착

### Skewness — 비대칭도 (3개)

`{sig}_skew_{n}d`는 lookback 마지막 n일 값의 왜도(skewness). 값들을 평균 0, 표준편차 1로 정규화한 뒤 3제곱의 평균으로 계산. 데이터가 좌우 대칭이면 0이고, 오른쪽으로 긴 꼬리가 생기면 양수. 바이럴 초기에 하루만 크게 튀어도 최근 윈도우의 skewness가 양수로 급등하는 특성 활용. n = 7, 14, 30 (최소 7개 데이터포인트 필요하여 3d/5d 제외)

- `{sig}_skew_7d` — 최근 1주 비대칭. 급성 스파이크 즉시 감지
- `{sig}_skew_14d` — 최근 2주 비대칭
- `{sig}_skew_30d` — 최근 1달 비대칭. 더 넓은 시야

### Kurtosis — 뾰족함 (3개)

`{sig}_kurt_{n}d`는 lookback 마지막 n일 값의 첨도(kurtosis). 정규화된 값의 4제곱 평균에서 3을 뺀 값으로, 정규분포이면 0이고 극단값이 존재하면 양수. 값들이 비슷비슷하면 낮고, 하나가 극단적으로 튀면 높음. "이 윈도우에 스파이크가 존재했는가"를 직접 측정. n = 7, 14, 30

- `{sig}_kurt_7d` — 최근 1주 뾰족함
- `{sig}_kurt_14d` — 최근 2주 뾰족함
- `{sig}_kurt_30d` — 최근 1달 뾰족함

### Spikiness — 최대값 돌출도 (5개)

`{sig}_spikiness_{n}d`는 `max(arr_lb[-n:]) / (mean(arr_lb[-n:]) + ε)`로 최근 n일 내 최대값이 평균 대비 얼마나 튀는지를 측정. skewness/kurtosis보다 단순하지만 직관적이며, 3일이라는 짧은 윈도우에서도 계산 가능. n = 3, 5, 7, 14, 30. 클리핑 없음 (burst 강도 자체가 정보)

- `{sig}_spikiness_3d` — 최근 3일 돌출. "지금 이 순간 터지고 있는가"를 가장 빠르게 포착
- `{sig}_spikiness_5d` — 최근 5일 돌출
- `{sig}_spikiness_7d` — 최근 1주 돌출
- `{sig}_spikiness_14d` — 최근 2주 돌출
- `{sig}_spikiness_30d` — 최근 1달 돌출

## 시그널 피처 — G. Stability (시그널당 4개)

"얼마나 안정적이었고, 안정성이 변하고 있는가"를 측정하는 피처. lookback 60일 동안 안정적이던 키워드가 갑자기 흔들리기 시작하면 그 자체가 바이럴 전조일 수 있음

### CV — 변동계수 (3개)

`{sig}_cv_{n}d`는 `std(arr_lb[-n:]) / (mean(arr_lb[-n:]) + ε)`로 변동계수(coefficient of variation). 표준편차를 평균으로 나누어 스케일 중립적 변동성 지표를 구성. 0에 가까우면 안정적이고, 클수록 들쑥날쑥. n = 7, 14, 30 (3d/5d는 표준편차 계산에 데이터포인트 부족). 클리핑 범위 0~10

- `{sig}_cv_7d` — 최근 1주 변동성
- `{sig}_cv_14d` — 최근 2주 변동성
- `{sig}_cv_30d` — 최근 1달 변동성

### CV Change — 안정성 변화 (1개)

`{sig}_cv_change`는 `cv(arr_lb[-14:]) - cv(arr_lb[:30])`로 lookback 60일 내에서 안정성이 어떻게 변했는지를 측정. arr_lb[-14:]는 최근 14일의 변동계수이고, arr_lb[:30]은 lookback 초기 30일의 변동계수. 양수면 최근이 과거보다 불안정해진 것이고, 음수면 안정화된 것. 전부 60일 lookback 안에서 계산되므로 새 키워드가 추론 시 들어와도 동일하게 작동

## 시그널 피처 — H. Lag (시그널당 5개)

"특정 시점에 실제로 얼마였는가"를 직접 제공하는 피처. 위의 모든 피처가 윈도우 기반 요약 통계인 반면, lag는 특정 날의 실제값을 정규화하여 전달. Kaggle M5 시계열 예측 대회 우승 솔루션에서 가장 강력한 피처로 입증

`{sig}_lag_{n}d`는 `arr_lb[-n] / (baseline + ε)`로 n일 전의 값을 60일 평균으로 나눈 것. n = 1, 3, 7, 14, 30

- `{sig}_lag_1d` — 어제 정규화 값. 가장 최근 정보
- `{sig}_lag_3d` — 3일 전 정규화 값
- `{sig}_lag_7d` — 7일 전 정규화 값. "지난주 이맘때"
- `{sig}_lag_14d` — 14일 전 정규화 값. "2주 전 이맘때"
- `{sig}_lag_30d` — 30일 전 정규화 값. "한 달 전 이맘때"

## 시그널 피처 — I. Raw Std (시그널당 3개)

"실제 변동 크기가 얼마인가"를 측정하는 절대 표준편차 피처. CV(std/mean)는 스케일 중립적 변동성이지만, raw std는 절대 변동 크기를 직접 제공. 이전 50 피처 모델에서 peak_time 예측의 SHAP 1위가 search_std_7d였으며, CV로 대체 시 성능이 하락한 것이 확인되어 별도 추가

트리 모델은 곱셈을 직접 수행하지 못하므로, cv(std/mean)와 volume(mean)이 있어도 std = cv × volume을 모델이 유도할 수 없음. 따라서 raw std를 명시적으로 제공해야 함. n = 7, 14, 30 (3d/5d는 표준편차 계산에 데이터포인트 부족). 클리핑 없음

- `{sig}_std_7d` — 최근 1주 절대 변동 크기
- `{sig}_std_14d` — 최근 2주 절대 변동 크기
- `{sig}_std_30d` — 최근 1달 절대 변동 크기

## 시그널 피처 — J. Position (시그널당 5개)

"최근값이 n일 최고점 대비 어디 있는가"를 측정하는 피처. level이 60일 전체 평균 대비 위치를 나타낸다면, position은 최근 n일 최고점 대비 위치를 나타냄. 1.0에 가까우면 현재가 n일 내 최고 수준이고, 0에 가까우면 최고점 대비 크게 하락한 상태

`{sig}_pos_{n}d`는 `mean(arr_lb[-3:]) / (max(arr_lb[-n:]) + ε)`로 분자를 단일값(arr_lb[-1])이 아닌 3일 이동평균으로 smoothing하여 하루 노이즈 완화. n = 3, 5, 7, 14, 30

- `{sig}_pos_3d` — 최근 3일 최고점 대비 위치
- `{sig}_pos_5d` — 최근 5일 최고점 대비 위치
- `{sig}_pos_7d` — 최근 1주 최고점 대비 위치
- `{sig}_pos_14d` — 최근 2주 최고점 대비 위치
- `{sig}_pos_30d` — 최근 1달 최고점 대비 위치

## 시그널 피처 — K. Peak Recency (시그널당 1개)

"최고점이 며칠 전에 나타났는가"를 측정하는 피처. position이 최고점 대비 "값 차이"를 나타낸다면, peak recency는 최고점의 "시간 거리"를 나타냄

`days_since_{sig}_max_14d`는 `13 - argmax(arr_lb[-14:])`로 최근 14일 내 최고점 이후 경과한 날 수. 0이면 어제(t-1)가 최고점이고, 13이면 14일 전이 최고점

## 교차 시그널 피처 (8개)

서로 다른 시그널 간의 관계를 포착하는 피처. 검색만 올라가는 건 일시적 관심일 수 있지만, 클릭도 블로그도 인스타그램도 같이 움직이면 실제 확산

### 검색-클릭 교차 (4개)

`click_search_ratio`는 `click_level_7d / (search_level_7d + ε)`로 검색 활성도 대비 클릭 활성도의 비율. 정규화된 level끼리의 비율이므로 절대 MA를 나누던 기존의 스케일 문제가 없음. 클리핑 범위 0~50

`click_lead_7d`는 `click_growth_7d - search_growth_7d`로 클릭 성장률에서 검색 성장률을 뺀 값. 양수면 클릭이 검색보다 먼저 반응하고 있다는 신호. 쇼핑 클릭이 검색을 5~7일 선행하는 패턴이 실제 데이터에서 관찰됨

`click_lead_14d`는 위와 동일한 계산을 14일 윈도우에 적용

`click_search_pos_gap`은 `click_level_7d - search_level_7d`로 클릭과 검색의 상대 위치 차이. 양수면 클릭이 검색보다 baseline 대비 더 높은 수준

### 플랫폼-검색 교차 (4개)

`blog_lead_7d`는 `blog_growth_7d - search_growth_7d`로 블로그 성장이 검색을 선행하는 정도. SNS 버즈가 검색보다 먼저 급등하면 바이럴 초기 신호

`blog_search_ratio`는 `blog_level_7d / (search_level_7d + ε)`로 검색 대비 블로그 활성도. 클리핑 범위 0~50

`instagram_lead_7d`는 인스타그램 기준 동일 계산

`instagram_search_ratio`는 인스타그램 기준 동일 계산

## 캘린더 피처 (2개)

시간적 맥락을 제공하는 피처. 식품 키워드는 주중/주말 패턴(주말 베이킹 검색 증가 등)과 월별 패턴(3월 화이트데이, 12월 크리스마스 등)이 존재

`day_of_week`는 0~6 (월요일=0, 일요일=6). 60일 lookback에 주중과 주말이 섞여있어 baseline이 평균화되는데, 모델이 "토요일이라 오른 것"과 "바이럴이라 오른 것"을 구분할 수 있게 해줌

`month`는 1~12. 4년치 데이터에서 각 월이 3~4번 등장하므로 학습 데이터가 제한적이지만, 계절형 키워드의 패턴을 부분적으로 포착 가능

## 라벨 (2개)

### virality_score — Z-score 기반 바이럴 강도 (주 타겟)

`past_mean`은 lookback 60일 검색량 평균, `past_std`는 표준편차, `future_max`는 forward 14일 내 최대 검색량, `abs_change`는 `future_max - past_mean`

virality_score는 `abs_change / (past_std + ε)`로 계산하되, `abs_change`가 `MIN_ABS_CHANGE`(기본값 10) 미만이면 0으로 설정

기존 ratio 방식(`future_max / past_mean`)은 "몇 배 올랐는가"를 측정하여 성장 규모는 알 수 있으나 "이 키워드 기준으로 얼마나 비정상인가"는 판단 불가. 매주 2배씩 오르내리는 키워드가 또 2배 오르면 ratio=2.0이지만 z-score는 낮음. 반대로 lookback 60일 동안 안정적이던 키워드가 1.3배만 올라도 z-score는 높음. 후자가 진짜 바이럴 신호

`MIN_ABS_CHANGE` 하한은 z-score의 약점(검색량 5에서 10으로 증가하면 z=5가 나올 수 있는 현상)을 보완. 절대 변화량이 기준 미만이면 z=0으로 처리하여 노이즈 차단

### peak_time — 최고점 도달일 (보조 타겟)

`argmax(search[t:t+14])`로 향후 14일 중 최대 검색량이 발생하는 날(0~13)

## NaN 처리

search와 click은 forward fill 후 잔여 NaN을 0으로 채움. bfill은 미래 데이터로 과거 결측을 채우는 시간적 누수를 발생시키므로 사용하지 않음

멘션(blog, instagram)도 ffill → 0. 멘션이 없는 키워드는 전 기간 0으로 처리

## 품질 필터

lookback 60일의 앞 30일(가장 오래된 절반)이 전부 비활성(원본 NaN 또는 0)이면 해당 샘플 제외. 키워드가 해당 기간에 아직 존재하지 않았거나 검색량이 전혀 없었던 경우를 걸러내는 목적. 추가로 lookback 전체의 search 표준편차가 0이면 제외 (z-score 계산 불가)

## 극단값 클리핑

level은 0~30, growth는 -2~20, cv는 0~10, ratio(교차 시그널)는 0~50 범위로 클리핑. scale, lag, skew, kurt, RSI, acceleration, spikiness, std, position, peak recency, calendar는 클리핑 없음

## 구성 요약

시그널 피처는 4개 시그널(search, click, blog, instagram) 각각에 50개씩 총 200개. 50개는 Scale 5 + Level 5 + Momentum 5 + Acceleration 3 + RSI 3 + Shape 11(skew 3 + kurt 3 + spikiness 5) + Stability 4(cv 3 + cv_change 1) + Lag 5 + Raw Std 3 + Position 5 + Peak Recency 1로 구성. 교차 시그널 피처는 검색-클릭 4개와 플랫폼-검색 4개로 총 8개. 캘린더 피처 2개. 전체 합산 210개 피처

라벨은 virality_score(z-score 기반 바이럴 강도)와 peak_time(최고점 도달일) 2개
