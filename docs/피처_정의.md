# 피처 정의

## 개요

| 항목 | 내용 |
|------|------|
| **계산 윈도우** | 60일 lookback (t-60 ~ t-1 기준 계산) |
| **레이블 윈도우** | 14일 forward (t ~ t+13) |
| **데이터셋 기간** | 2022-05-01 ~ 2026-02-14 |
| **Phase 1 피처 수** | 24개 (검색량 + 클릭수) |
| **최종 목표 피처 수** | 51개 (SomeTrend + Demographic 추가 시) |

---

## 사용 데이터 및 절댓값 선택 이유

| 파일 | 사용 여부 | 비고 |
|------|----------|------|
| `data/raw/search_absolute.csv` | ✅ Phase 1 사용 | 검색량 절댓값 |
| `data/raw/shopping_click_absolute.csv` | ✅ Phase 1 사용 | 클릭수 절댓값 |
| `data/raw/search_trend.csv` | ❌ 미사용 | 상대값 (0~100) |
| `data/raw/shopping_click_trend.csv` | ❌ 미사용 | 상대값 (0~100) |

**절댓값을 선택한 이유:**
- 상대값(0~100)은 조회 기간 전체 최고점=100으로 정규화 → 이미 역대 최고 근방에 있는 키워드는 성장 여력이 있어도 높게 표시됨
- 절댓값은 실제 검색 횟수 → virality_score = `future14_max / past60_mean` 비율이 실질 성장률을 의미
- growth rate, slope 등 비율 기반 피처는 절댓값·상대값 모두 동일하지만, 레이블 계산의 직관성 측면에서 절댓값이 더 명확
- NaN 처리: forward-fill → backward-fill → 0 순서로 보완

## Phase 1 피처 (현재 구현 가능: 24개)

### 검색량 기반 피처 (10개)

> 모두 `search_absolute.csv` 기반, 최근 60일 window 내에서 계산

| # | Feature 이름 | 계산 방법 | 의미 |
|---|-------------|----------|------|
| 1 | `search_ma_7d` | mean(search[t-7 : t-1]) | 최근 7일 평균 검색량 |
| 2 | `search_growth_3d` | mean(search[t-3:t-1]) / (mean(search[t-6:t-4]) + ε) − 1 | 초단기 검색 급등률 |
| 3 | `search_growth_7d` | mean(search[t-7:t-1]) / (mean(search[t-14:t-8]) + ε) − 1 | 단기 검색 증가율 |
| 4 | `search_growth_14d` | mean(search[t-14:t-1]) / (mean(search[t-28:t-15]) + ε) − 1 | 중기 검색 증가율 |
| 5 | `search_slope_7d` | linregress(search[t-7:t-1]).slope | 최근 7일 선형회귀 기울기 |
| 6 | `search_slope_14d` | linregress(search[t-14:t-1]).slope | 최근 14일 선형회귀 기울기 |
| 7 | `search_acceleration` | search_growth_7d − search_growth_14d | 검색 상승 가속도 |
| 8 | `search_std_7d` | std(search[t-7:t-1]) | 최근 7일 검색량 표준편차 |
| 9 | `search_pos_14d` | search[t-1] / (max(search[t-14:t-1]) + ε) | 현재값이 14일 최고점 대비 위치 |
| 10 | `days_since_max_14d` | t-1 − argmax(search[t-14:t-1]) | 14일 내 최고점으로부터 경과일 |

## 레이블 (2개)

| 컬럼명 | 계산 방법 | 의미 |
|--------|----------|------|
| `virality_score` | max(search[t : t+13]) / (mean(search[t-60 : t-1]) + ε) | 향후 14일 최대 검색량 / 과거 60일 평균 → 실질 성장 배율 |
| `peak_time` | argmax(search[t : t+13]) | 향후 14일 중 최대값이 발생하는 날 (0~13) |

**virality_score 해석 예시:**
- 1.0 미만: 감소 추세
- 1.0 ~ 1.5: 현 수준 유지
- 1.5 ~ 2.5: 완만한 상승
- 2.5 이상: 바이럴 가능성 높음

## 구현 참고사항

- **ε (epsilon)**: 1e-6 (0 나누기 방지용)
- **NaN 처리 순서**: forward-fill → backward-fill → 0
- **60일 window 내 유효 데이터 최소 기준**: 30일 이상 유효값 존재 시 샘플 포함 (미달 시 제외)
- **인코딩**: `encoding='utf-8-sig'` (BOM 포함 UTF-8)
- **출력 파일**: `data/processed/dataset_phase1.csv`
